Nestvane

Android, running inside an app on your iPhone.

Nestvane starts a full Android 17 system in an iPhone app and shows it on your screen. Install Android apps from APK files, use them with touch, and keep their data between launches.

Today

What works today

Nestvane is early. This is what the test version does now.

  • Android 17

    The home screen, Settings and Files, built from the Android Open Source Project.

  • APK files

    Open an APK with Nestvane from another app, or choose Install APK in Nestvane.

  • Network

    Android apps use your iPhone’s Wi-Fi or cellular connection.

  • Shared files

    Android’s shared storage is a folder in the Files app: On My iPhone → Nestvane → Android. Files you put there appear in Android the next time it starts.

  • Home screen widgets

    Add widgets from installed apps to the Android home screen.

  • Your iPhone’s clock and battery

    Android shows your time zone and battery level.

Under the hood

How it works

iOS does not let an app create new machine code while it runs, so Nestvane cannot translate Android’s code on the fly. It needs no jailbreak and no hypervisor. It is an ordinary app made of four pieces.

  1. Android, rebuilt

    Android 17 is compiled from source with a few processor registers left unused. Nestvane keeps its own bookkeeping in them while Android’s code runs. It is still the real system: the same start-up, home screen, Settings and package installer.

  2. Code translated ahead of time

    Before the app is built, each of Android’s programs and libraries, about 1,230 of them, is rewritten into code that iOS accepts. The result ships inside the app as signed code and runs directly on the processor.

  3. A Linux kernel layer in the app

    Android expects Linux underneath. Nestvane provides that layer itself: processes and scheduling, system calls, files, sockets, and Binder, the channel Android’s parts use to talk to each other.

  4. An interpreter for the rest

    Code that was not translated in advance, such as the native libraries some apps bring in their APK, is run one instruction at a time by an interpreter. That works, but it is much slower.

The screen is drawn with the iPhone’s graphics processor and shown at 60 frames a second. For the details, read the documentation on GitHub.

Know before you ask

Limits

  • Nestvane is in private testing and is not available to download yet.
  • Video and audio playback are not available yet.
  • There are no Google apps or Google Play services. Apps that require them will not run.
  • Apps that bring their own native code run noticeably slower than on an Android phone.
  • Some apps do not start. Tell us which ones matter to you.
  • Files you add to the shared folder from the iPhone appear in Android only after Android restarts.
  • Android’s network connection is IPv4 only.

Requirements

iOS 26 or later. Nestvane has been tested on iPhone 15 Pro and iPhone 17 Pro.

The app is a download of about 1 GB and uses about 2.4 to 2.7 GB of memory while Android runs.

Your data

Privacy policy

Effective November 21, 2026.

What Nestvane collects

Nothing. Nestvane has no account, no advertising and no analytics, and it does not send your files, your installed apps or your activity to AtomSprout.

Network

When Nestvane starts, it makes one request to Apple’s connectivity check at captive.apple.com so that iOS can ask whether Nestvane may use the network. Android itself checks its connection the way Android devices do, by contacting Google’s connectivity check servers. Everything else on the network is traffic of the Android apps you install, which handle your data under their own privacy policies.

Your data

Android’s apps and their data are stored inside Nestvane on your iPhone. Shared files are in the Nestvane folder of the Files app. Deleting Nestvane removes all of it.

Contact

If you email us, we receive your email address and the information you choose to share so we can respond. For privacy questions, email atomsprout@gmail.com.
