Five registers kept free, and one indirect branch

Android's code does not touch these five, so the rewritten code has somewhere to keep its own state

RegisterUsed for
x25The context of the current guest thread
x26The jump table: where the translated code for a guest address is
x27The chunk table of the address space
x28Scratch
x18Reserved by iOS; the guest may not use it
